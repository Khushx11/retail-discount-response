# VISUELLE 2.0 forecasting inputs

This directory contains the four unmodified source CSVs used in the project, shared with permission from the dataset publisher.

- `sales.csv` contains weekly observed sales and product metadata.
- `price_discount_series.csv` contains weekly discounts.
- `restocks.csv` contains delivery records.
- `vis2_gtrends_data.csv` contains category search trends.

Cite Geri Skenderi, Christian Joppi, Matteo Denitto, Berniero Scarpa and Marco Cristani. *The Multi-Modal Universe of Fast-Fashion: The Visuelle 2.0 Benchmark*, CVPR Workshops, 2022, pp. 2241–2246. See Humatics Lab for the full dataset and terms for further reuse. [Publisher and citation](https://humaticslab.github.io/forecasting/visuelle)

Check these files against the [study manifest](../../docs/visuelle2.sha256) or follow the [reproduction instructions](../../docs/reproduce.md).
